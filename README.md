# Lingua Latina medicinalis — латинско-русский переводчик для студентов СБМК

Учебный сайт-переводчик **с латинского на русский и с русского на латинский**, сделанный для студентов
**Сахалинского базового медицинского колледжа (СБМК)**, г. Южно-Сахалинск.

Переводчик работает **только по словарям учебников**:

- В.И. Кравченко «Латинский язык для медицинских колледжей и училищ» — латинско-русский словарь (с. 327–363) и таблицы терминоэлементов;
- Ю.И. Городкова «Латинский язык (для медицинских и фармацевтических колледжей и училищ)», КНОРУС, 2017 — латинско-русский словарь (с. 221–244); добавлены слова, которых нет у Кравченко.

У каждой статьи указан источник («Кравченко, словарь, с. N» или «Городкова, словарь»).
Слов, которых нет в словаре, сайт не переводит и подсвечивает красным, поэтому ответ всегда совпадает с учебником.

## Возможности

- **Латынь → русский.** Слова можно вводить в любой форме (*cordis, venarum, tabulettas*):
  сайт строит все падежные формы словарных слов, находит словарную форму и показывает падеж и число.
  Учитывается контекст (*tinctura Valerianae* → «настойка валерианы», *in vena dextra* → «в вене правой»),
  устойчивые сочетания из словаря (*oleum Ricini, acidum boricum*) распознаются целиком.
- **Русский → латынь.** Русские слова ищутся с учётом окончаний (почки, почкой, почек → *ren*).
  По окончанию определяется падеж, прилагательное согласуется с существительным в роде, числе и падеже,
  а предлог ставит нужный падеж: «раствор борной кислоты» → *solutio acidi borici*,
  «таблетки от кашля» → *tabulettae contra tussim*.
- **Таблицы форм.** По клику на слово открывается статья с полной таблицей склонения
  (5 склонений, прилагательные 1–2 и 3 склонения, сравнительная степень) или спряжения.
- **Словарь.** Поиск по-латински и по-русски, в том числе по любой падежной форме, плюс фильтр по буквам.
- **Терминоэлементы.** Приставки, греческие терминоэлементы и таблицы по системам органов.
  Если слова нет в словаре, сайт может предложить **подсказку-разбор** (*gastr- + -itis* = желудок + воспаление),
  но не выдаёт её за перевод.
- Работает без интернета и без сервера: это обычные HTML, CSS и JS. Есть мобильная версия и тёмная тема.

## Ограничения

- Падеж при переводе выбирается автоматически по окончаниям. Это подсказка, а не замена правилам:
  проверяйте результат по таблице форм.

## Как опубликовать на GitHub Pages

1. Создайте на GitHub новый репозиторий, например `latin-sbmk`.
2. Загрузите в корень репозитория **всё содержимое этой папки** (`index.html`, `css/`, `js/`, `data/`, `tools/`, `README.md`, `.nojekyll`):
   на странице репозитория нажмите **Add file → Upload files** или используйте `git push`.
3. Откройте **Settings → Pages**. В разделе *Build and deployment* выберите
   **Source: Deploy from a branch**, затем **Branch: `main`**, папку **`/ (root)`** и нажмите **Save**.
4. Через 1–2 минуты сайт будет доступен по адресу `https://<ваш-логин>.github.io/latin-sbmk/`.

Сайт можно открыть и локально, двойным щелчком по `index.html`.

## Как добавить или исправить слова

Словарь хранится в простых текстовых файлах в папке `tools/`:

- `tools/raw/pNNN.txt` — страницы словаря, по одной статье в строке:
  ```
  abdomen, -inis, n — живот
  dexter, -tra, -trum — правый
  vulgaris, -e — обыкновенный
  jungo, -ere — соединять
  sine — предл. с abl. без
  oleum Ricini — касторовое масло
  ```
  Формат: словарная форма, окончание родительного падежа (или окончания прилагательного), род,
  затем « — » и перевод. Пояснения пишутся в скобках.
- `tools/raw/g_gorodkova.txt` — слова из словаря Ю.И. Городковой, которых нет у Кравченко (тот же формат).
- `tools/tables.txt` — таблицы по системам органов (раздел | русский | латинский | терминоэлемент | примеры).
- `tools/elements.txt` — приставки и терминоэлементы.

После правки соберите файл данных (нужен Python 3):

```bash
python3 tools/build.py
```

Команда пересоздаёт `data/dictionary.js`. Склонение и поиск форм сайт строит сам по указанной грамматике.
Например, чтобы добавить новую страницу, создайте файл `tools/raw/pNNN.txt` с её статьями и запустите сборку.

## Структура проекта

```
index.html          — страница сайта
css/style.css       — оформление
js/morph.js         — морфология: склонение, спряжение, русские окончания
js/app.js           — переводчик и интерфейс
data/dictionary.js  — данные словаря (генерируется)
tools/              — исходные тексты словаря и скрипт сборки
```
